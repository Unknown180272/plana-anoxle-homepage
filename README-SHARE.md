# Plana Anoxle Light — shareable homepage

Based on Anoxle Startpage by anoxle. Includes an optimized Plana video and tab-visibility pause/resume.

**Warning:** Your own local Firefox preferences, links, and saved background uploads are NOT included; those are in the browser storage of 127.0.0.1. Export settings via Anoxle and import them at the hosted site if you need the same layout. Exported settings can contain private shortcuts, so review before sharing.

## Publish

Use the companion script `publish-github-pages.sh` from the root folder. It requires GitHub CLI `gh`, `git`, and a GitHub login. It creates a new public repository and asks you to enable Pages via repository Settings > Pages > Deploy from branch > main / root.

Be certain that you have rights to publicly redistribute any included video/art assets.
